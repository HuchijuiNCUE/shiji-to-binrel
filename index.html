史記 to Binrel

《史記》人物提取、人物關係分析與資料匯出工具

A2 第二版｜使用自己的 ChatGPT，不需 API Key

步驟一：輸入《史記》原文

請貼入文言文，每個段落以檔名開頭， 例如「項羽本紀001」。

步驟二：提取人物

產生人物提取指令後，複製並貼入 ChatGPT。 待 ChatGPT 回傳人物名單，再貼回下方保存。

開啟 ChatGPT

步驟三：分析人物關係

請先完成步驟二並保存人物名單， 再選擇 MA 或 Binrel 分析格式。

開啟 ChatGPT

先複製上面的關係分析指令，再開啟 ChatGPT 貼上。 ChatGPT 完成分析後，請將表格貼到步驟四。

步驟四：匯入人物關係分析結果

步驟五：人物關係視覺化

下載 Binrel 格式 CSV 後，可使用 DocuSky 的二元視覺化關聯圖進行人物關係研究。
